# Sondhan — রক্তের অনুরোধ ও নোটিফিকেশন: সেটআপ গাইড

## এটা কী করে
সিকার "অনুরোধ পাঠান" চাপলে → দাতার **ইনবক্সে** (`inbox.html`) অনুরোধ আসে, হোমপেজে 🔔 ব্যাজ জ্বলে, আর দাতা
নোটিফিকেশন চালু করে থাকলে **ফোনে পুশ** আসে। দাতা "রাজি আছি / এখন পারছি না" চাপলে সিকারও একইভাবে জানতে পান।

- সিকারের ফোন নম্বর দাতা **রাজি হলে**ই দেখতে পান; দাতার যোগাযোগ সিকার **রাজি হলে**ই পান।
- একই দাতাকে একই সিকার ২৪ ঘণ্টায় একবারই অনুরোধ পাঠাতে পারেন; ১০ সেকেন্ডের গতি-সীমা; সার্ভারে ঘণ্টায় ১৫টি পুশের সীমা।
- **পুশ ছাড়াও ইনবক্স পুরো কাজ করে।** পুশ হলো উপরের বাড়তি স্তর।

## চালু করার ধাপ (৩টি — প্রথমটি না করলে কিছুই চালু হবে না)

### ধাপ ১ — Firestore নিয়ম Publish করুন (আবশ্যক, ~৫ মিনিট)
1. Firebase Console → আপনার প্রজেক্ট (**life-drop-d4784**) → **Firestore Database → Rules**।
2. বর্তমান নিয়ম কোথাও কপি করে **ব্যাকআপ** রাখুন।
3. রেপোর `firestore.rules` ফাইলের **পুরোটা** পেস্ট করে **Publish** চাপুন।
4. (ঐচ্ছিক, প্রযুক্তিগত) পেস্টের আগে `cd tests/rules && npm i && npm test` — ৫৭টি নিরাপত্তা-পরীক্ষা পাস করা উচিত।

এই ধাপের পর ইনবক্স, 🔔 ব্যাজ ও "অনুরোধ পাঠান" পুরোপুরি কাজ করবে (পুশ ছাড়া)।

### ধাপ ২ — পুশের "VAPID key" বসান (~৩ মিনিট)
1. Firebase Console → ⚙ **Project settings → Cloud Messaging** ট্যাব।
2. নিচে **Web Push certificates → Generate key pair**।
3. যে লম্বা key (সাধারণত `B...` দিয়ে শুরু) দেখাবে সেটা কপি করুন — এটা **পাবলিক key**, গোপন নয়।
4. রেপোর `notify.js`-এ `export const VAPID_KEY = '';` লাইনে বসান। (আমাকে key টা পাঠালে আমি বসিয়ে দেব।)

### ধাপ ৩ — সার্ভার-সংযোগ (পুশ পাঠানোর চাবি) (~৫ মিনিট)
1. Firebase Console → ⚙ **Project settings → Service accounts → Generate new private key** → একটি `.json` ফাইল নামবে।
   ⚠️ **এই ফাইল গোপন।** কাউকে পাঠাবেন না, চ্যাটে পেস্ট করবেন না, GitHub-এ রাখবেন না।
2. Vercel → প্রজেক্ট **life-drop → Settings → Environment Variables → Add**:
   - Name: `FIREBASE_SERVICE_ACCOUNT`
   - Value: `.json` ফাইলের **পুরো লেখা** পেস্ট করুন
   - Environments: Production (এবং চাইলে Preview)
3. Vercel-এ **Redeploy** করুন (env বদলালে নতুন ডেপ্লয় লাগে)।

এই ধাপ না করলে সার্ভার `501 not-configured` দেয়; ইনবক্স ও ব্যাজ তবুও চলে।

## পরীক্ষা করার সহজ উপায়
1. দুটি আলাদা Google অ্যাকাউন্ট/ডিভাইস নিন — **A** (দাতা, নিবন্ধিত) ও **B** (সিকার)।
2. **A**-এর ফোনে (Android Chrome) `sondhan.org/inbox.html` খুলে "নোটিফিকেশন চালু করুন" → Allow।
3. **B** দিয়ে সার্চ → A-কে খুঁজে → "অনুরোধ পাঠান"।
4. A-এর ফোনে নোটিফিকেশন আসবে; ট্যাপ করলে ইনবক্স খুলবে; "রাজি আছি" চাপুন।
5. B-এর কাছে "অনুরোধ গ্রহণ করা হয়েছে" নোটিফিকেশন আসবে; ইনবক্সে "যোগাযোগ করুন" দেখাবে।

| ফাইল | কাজ |

| `firestore.rules` | `donorRequests`, সিকারের ফোনের সাব-ডক, `fcmTokens`, সম্মতিভিত্তিক যোগাযোগ-শেয়ারিং |
| `inbox.html` | ইনবক্স (পাওয়া/পাঠানো, রাজি/অপারগ, যোগাযোগ, পুশ চালু/বন্ধ) |

| `api/notify.js` | সার্ভার-ফাংশন: যাচাই → ডুপ্লিকেট/সীমা → FCM-এ পাঠানো |

| `index.html` / `profile.html` | 🔔 ব্যাজ / "আমার অনুরোধ" লিংক |

## গোপনীয়তা
- পুশে কখনো ফোন নম্বর বা ইমেইল থাকে না — শুধু নাম ও বার্তার শুরুর অংশ।
- ডিভাইস টোকেন শুধু মালিক পড়তে/লিখতে পারেন (সর্বোচ্চ ৫ ডিভাইস); সার্ভার শুধু পাঠানোর সময় পড়ে।
- `privacy.html`-এ নোটিফিকেশন ও এই ডেটা (ডিভাইস টোকেন, অনুরোধের বার্তা) নিয়ে এক অনুচ্ছেদ যোগ করা উচিত — আইনি লেখা আপনার সিদ্ধান্ত।
